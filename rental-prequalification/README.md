# Rental Prequalification Widget

Standalone responsive calculator for preliminary rental qualification categories.

## Public URL

Once GitHub Pages finishes publishing the `main` branch, use:

`https://adambgarrett.github.io/us-metro-zillow-widget/rental-prequalification/`

## Wix Classic embed

1. Add an **Embed Code / Embed a Site** element.
2. Use the public URL above.
3. Start with an iframe height of about **1,050 px** on desktop.
4. Test the mobile layout and increase the height if expanded fields or results are clipped.

## Notes

- The calculator does not run a credit check or collect sensitive documents.
- It supports rental assistance, no-score and foreign-credit pathways, and voluntary higher-rent proposals in eligible credit-risk cases.
- Final approval, insurance, lease-guaranty eligibility, deposits, and other terms remain subject to verification, underwriting, provider participation, and applicable law.
