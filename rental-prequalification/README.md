# Rental prequalification widget

Responsive applicant-facing calculator for the current rental qualification matrix.

## Current features

- Eight income-to-rent tiers, including 2.00x-2.24x and below 2.00x.
- Credit bands from 800-850 through below 520.
- Standard and optional low-debt (LD) pathways.
- Expanded LD exception routes for some 560-599 and 520-559 results.
- Rent-and-debt percentage, reserve, and enhanced remaining-income estimates.
- Rental-assistance calculation using tenant-paid rent plus utility allowance.
- No-score and foreign-credit alternative-review pathways.
- Voluntary higher-rent note without changing the income-ratio calculation.

## Public URL

`https://adambgarrett.github.io/us-metro-zillow-widget/rental-prequalification/`

## Wix Classic embed

1. Add an **Embed Code / Embed a Site** element.
2. Use the public URL above.
3. Start with an iframe height of approximately **1,500-1,800 px**.
4. Test mobile separately because expanded LD fields and result cards may require additional height.
5. Place the complete written matrix, legal limitations, and application criteria beneath the widget on the Wix page.

## Important

This calculator is a preliminary informational guide. It does not run a credit check, reserve a property, or guarantee approval. Final implementation and applicant-facing criteria should receive Virginia attorney and supervising-broker review before operational use.
